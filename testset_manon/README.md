# Dataset Description

Each file is named `<SubjectID>_<joint>.npz` (e.g. `Subject08_knee.npz`) and contains
synchronized IMU data and derived quantities for one subject and one joint.

**Source:** SimTK study20 dataset (Xsens IMUs, optical motion capture at 100 Hz).
**Joint covered:** knee (`femur_r_imu` → `tibia_r_imu`) and ankle (`tibia_r_imu` → `calcn_r_imu`).

---

## File Contents

| Key | Shape | Unit | Description |
|---|---|---|---|
| `acc_prox` | (N, 3) | m/s² | Proximal IMU accelerometer (X, Y, Z) |
| `gyr_prox` | (N, 3) | rad/s | Proximal IMU gyroscope (X, Y, Z) |
| `acc_dist` | (N, 3) | m/s² | Distal IMU accelerometer (X, Y, Z) |
| `gyr_dist` | (N, 3) | rad/s | Distal IMU gyroscope (X, Y, Z) |
| `j1` | (3,) | — | Joint axis unit vector estimated in the **proximal** IMU sensor frame (Olsson method via VQF) |
| `j2` | (3,) | — | Joint axis unit vector estimated in the **distal** IMU sensor frame (Olsson method via VQF) |
| `r1_est` | (3,) | m | Lever arm from proximal IMU to joint centre, expressed in the **proximal** sensor frame (estimated via `dfjimu.estimate_lever_arms`) |
| `r2_est` | (3,) | m | Lever arm from distal IMU to joint centre, expressed in the **distal** sensor frame (estimated via `dfjimu.estimate_lever_arms`) |
| `gt` | (N,) | degrees | Ground truth joint angle from optical motion capture IK (OpenSim) |
| `fs` | scalar | Hz | Sampling frequency (100.0 Hz) |

N = number of time samples after IMU–mocap synchronization (≈ 63 930 for Subject08 walking).

---

## Sensor Placement (knee joint)

- **Proximal IMU** (`femur_r_imu`): mounted on the right femur (thigh)
- **Distal IMU** (`tibia_r_imu`): mounted on the right tibia (shank)

For the ankle joint:
- **Proximal IMU** (`tibia_r_imu`): right tibia (shank)
- **Distal IMU** (`calcn_r_imu`): right calcaneus (foot)

---

## Synchronization

Raw IMU and mocap recordings are not hardware-synchronised.
Alignment is performed by cross-correlating the pelvis gyroscope Z signal with the
derivative of the mocap pelvis rotation angle. The IMU signal is trimmed by the
resulting sample offset so that `acc/gyr` and `gt` are time-aligned sample-by-sample.

---

## How to Load

```python
import numpy as np

d = np.load('Subject08_knee.npz')

acc_prox = d['acc_prox']   # (N, 3) proximal accelerometer
gyr_prox = d['gyr_prox']   # (N, 3) proximal gyroscope
acc_dist = d['acc_dist']   # (N, 3) distal accelerometer
gyr_dist = d['gyr_dist']   # (N, 3) distal gyroscope
j1  = d['j1']              # (3,)   joint axis in proximal frame
j2  = d['j2']              # (3,)   joint axis in distal frame
r1_est = d['r1_est']       # (3,)   lever arm proximal → joint centre [m]
r2_est = d['r2_est']       # (3,)   lever arm distal  → joint centre [m]
gt  = d['gt']              # (N,)   ground truth joint angle [deg]
fs  = float(d['fs'])       # 100.0 Hz
```
